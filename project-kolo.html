Kolo — Cooperative CivicTech for Migrant Integration CH

Status Platform / Kolo — Cooperative CivicTech for Migrant Integration CH

Live Demo: Suspended (portfolio project)
Portfolio: https://andriicoder1.github.io

A membership-based trade and social cooperative platform designed for the professional integration of migrants in Switzerland. Built with a focus on democratic governance, economic participation, and AI-driven media monitoring.

Platform Capabilities

Economics & Integration

  • Shared production, local trade, fairs, and sales channels.
  • Social programs: Language support, training, and a Talent Fund (micro-grants up to 3,000 CHF).

Democratic Governance

  • One member = one vote.
  • Elections of governing bodies and profit distribution.
  • Yes/No/Abstain voting system with a built-in survey builder.

Information & Analytics

  • AI-driven media monitoring across Swiss news sources (focusing on S-Status, integration, and employment).
  • Automatic RSS aggregation from 7 sources + manual article entry.

The project uses a monolithic architecture optimized for modularity:

  Architecture Overview
              
              Django 5.29 + DRF + PostgreSQL/SQLite
              ├── everest/ (Core auth/audit engine, inherited from EverRest project)
              ├── status_platform/ (Main application)
              │   ├── models.py — 10 custom data models
              │   ├── views.py — API endpoints & UI views
              │   ├── admin.py — Admin interface with proxy model inheritance
              │   └── templates/status/ — 26 HTML templates
              ├── static/ — Custom CSS/JS for the "Kolo" design system
              └── scrapper_news/ — RSS aggregator & AI integration

Key Features

Feature Description
3-Tier Membership Supporter (from 100 CHF), Participant (100 CHF), Activist (100 CHF) — each with distinct permissions.
Stripe Integration Sandbox/Test mode only. Webhook integration implemented for testing membership contributions.
JWT + Google OAuth Secure authentication with login-by-ID support.
AI Media Monitoring RSS aggregation from 7 Swiss sources + admin.ch REST API (8,000+ articles, 20+ departments).
AI Sentiment Analysis Ollama-powered (private inference, no data leaves the project) with batch summarization.
Parallax Glassmorphism UI Modern, responsive design optimized for mobile (iPhone/Android).
Multilingual Full i18n support: DE, FR, IT, EN, RU, UA.
Email Notifications Resend integration for registration, new topics, comments, and polls.
Audit Logging Privacy-first audit logs (REGISTER, LOGIN, VOTE, PAYMENT, etc.) built with GDPR/FADP principles in mind.

Implemented Features (Core Modules)

Core & Authentication

✅ Stripe Payments (Sandbox mode + Webhooks).

✅ 3-tier membership registration with auto-assigned user groups.

✅ JWT Authentication + social login via Google OAuth (FedCM).

✅ Proxy model inheritance in the Django Admin panel.

✅ Real-time participant counter and analytics from the database.

✅ Audit logging (REGISTER, LOGIN, VOTE, PAYMENT, CREATE_TOPIC, etc.).

Frontend & Parallax Glassmorphism

✅ Landing page with hero section, mission statements, and sector navigation.

✅ 7 sector pages with custom backgrounds (Trade, Crafts, Farming, Culture, Education, Technology).

✅ Registration, Login, User Dashboard, and 20+ informational pages.

✅ Fully mobile-responsive (iPhone/Android optimized) with a background carousel.

Voting & Forums

✅ Interactive voting system with survey switching (← →).

✅ Survey builder (Standard & Contextual).

✅ Dynamic voting buttons based on live options.

✅ Forum: Topics + threaded comments (guests have view-only access).

AI-Powered Media Monitoring

✅ RSS aggregation from SRF, SWI swissinfo (DE/FR/IT), Le Temps, RTS, Watson.

✅ Manual article input to cover restricted sources (Blick, NZZ, Tages-Anzeiger).

✅ AI analysis: Sentiment analysis + category detection + summarization.

✅ Advanced filters by language & sentiment.

✅ Auto-post generation for social media (LinkedIn, Facebook, Instagram, Telegram) based on platform metrics.

✅ Resume Registry (Admin Panel): Fully secure, superadmin-only interface for managing participant resumes. Includes expandable accordion cards, live search, and status management filters (New / Under Review / Job Offered / Hired).

Notifications (Resend API)

✅ Email triggers for: New registration, New topic created, New comment added, New poll created.

🔒 Security & Privacy

✅ Brute-force protection: 3 failed login attempts → temporary lock (using django-axes).

✅ DRF Throttling: Rate limiting for API endpoints.

✅ Security headers: CSRF, CSP (Content Security Policy), HSTS.

✅ Data privacy: All secrets are managed via environment variables (.env). Privacy-first architecture (GDPR/FADP-ready).

🐳 Deployment & Infrastructure

✅ Hosting: Render (Free Tier) + Neon (PostgreSQL).

✅ Static files: WhiteNoise for efficient serving.

✅ Stripe Webhooks: Configured for test payment event handling.
