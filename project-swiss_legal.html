⚖️ SwissLegalAssist — AI-Powered Legal Research Assistant

  • Status: Portfolio project (Live demo suspended)
  • Portfolio: https://andriicoder1.github.io

SwissLegalAssist is a full-stack AI assistant designed to help users navigate Swiss federal and cantonal law. The project demonstrates the implementation of a Retrieval-Augmented Generation (RAG) pipeline, processing thousands of legal documents and generating precise answers with source references.

⚠️ Disclaimer: This is a technical demonstration project. It does not provide legal advice and is not a commercial service. The live environment is suspended to comply with data privacy best practices.

Key Features

Feature Description

Architecture & Data Pipeline

id="the-project-is-built-as-a-modular-django-application-with-a-strong-focus-on-data-processing-and-ai-integration-">The project is built as a modular Django application with a strong focus on data processing and AI integration.

Data Ingestion (Scrapers & Parsers)

Legal data is aggregated from multiple official and open sources:

  • Fedlex (SPARQL): Official Swiss federal law (StGB, OR, ZGB, etc.).

  • OpenCaseLaw (REST API): Cantonal laws and court decisions.

  • LexWork / Cantonal APIs: Official law collections for SG and BE.

  • Data Transformation: Raw HTML/JSON is parsed into structured LegalDocument models, chunked, and prepared for vectorization.

Search & Retrieval (Embeddings)

  • Model: BAAI/bge-m3 (via Hugging Face) for generating dense vector embeddings.

  • Database: PostgreSQL with vector similarity search (Neon).

  • Process: User query → embedding → vector search → top-K relevant legal articles retrieved.

Answer Generation (LLM)

  • Provider: Groq API (Qwen model).

  • Process: Retrieved articles are injected into the prompt context. The LLM generates an answer strictly based on the provided legal texts.

  • References: Every generated answer includes links to the original source documents for verification.

Privacy & Security

  • Zero Data Retention (ZDR): Enabled on Groq to ensure AI queries are not stored.

  • Local Embeddings: Text vectorization via bge-m3 avoids sending raw user queries to third-party embedding APIs.

  • Environment Security: All API keys (Groq, HF, DB) are managed via .env variables.

⚠️ Disclaimer: The system is designed for informational purposes. AI-generated answers may contain inaccuracies and should be verified against the original legal source.

Deployment

  • The project is ready for containerized deployment (Docker) or PaaS (Render/Fly.io).
# Clone the repository
              git clone https://github.com/AndriiCoder1/swiss-legal-assist.git
              cd swiss-legal-assist
              
              # Setup virtual environment
              python -m venv venv
              source venv/bin/activate  # or venv\Scripts\activate on Windows
              
              # Install dependencies
              pip install -r requirements.txt
              
              # Run migrations
              python manage.py migrate
              
              # Start the server
              python manage.py runserver
